## 🔄 MEKANISME PENGUMPULAN DATA

### Langkah Operasional:
1. **Surat Resmi** dari Diskominfo ke 38 OPD — minta data sesuai daftar di atas
2. **Tim Kecil (3-5 orang)** dari Diskominfo/Bagian Organisasi lakukan:
   - Visitasi ke OPD prioritas (10 OPD pertama dengan layanan publik terbanyak)
   - FGD lintas OPD (2 sesi: kelompok urusan wajib & pilihan)
   - Digitalisasi dokumen (scan, OCR, kategorisasi)
3. **Tim Teknis** (kami) — konversi data ke format digital:
   - Excel → JSON → API → Website
   - Diagram BPMN → SVG interaktif
4. **Validasi** — tiap OPD mengesahkan draft PPB masing-masing
5. **Pengesahan** — Bupati menetapkan dengan Perbup
6. **Publikasi** — di website + distribusi ke OPD

### Estimasi Waktu:
| Tahap | Durasi | Keterangan |
|-------|--------|------------|
| Persiapan & pengumpulan data | 4-6 minggu | Surat, kunjungan, FGD |
| Pemetaan Level 0-1 | 2-3 minggu | Visi-Misi → Urusan |
| Pemetaan Level 2 per OPD | 8-12 minggu | Wawancara 38 OPD |
| Peta Relasi & Lintas Fungsi | 4-6 minggu | Validasi lintas OPD |
| Penyusunan SOP | 8-12 minggu | Turunan CFM |
| Pengesahan & Publikasi | 2-4 minggu | Perbup + website |
| **Total** | **28-43 minggu** | **~7-11 bulan** |

## 🚨 RISIKO & HAMBATAN

| Risiko | Dampak | Mitigasi |
|--------|--------|----------|
| OPD tidak kooperatif memberikan data | PPB tidak akurat | Surat pimpinan daerah (Bupati/Sekda) |
| Data tidak terstandarisasi | Sulit diintegrasi | Buat template seragam |
| Tidak punya akses API sistem digital | Data manual | Input manual + koordinasi teknis |
| Perubahan struktur organisasi | PPB perlu revisi | Desain fleksibel |
| SOP belum ada | Proses tidak terdokumentasi | Susun bersama OPD |
| Konflik kewenangan antar OPD | Relasi tidak jelas | Mediasi Sekda |
