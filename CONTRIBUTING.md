# Berkontribusi ke Pemdi Aceh Tengah

Terima kasih telah berkontribusi! 🎉

## Cara Berkontribusi

### 1. Data & Konten
- **Data OPD/SPBE** — Jika ada data terbaru, buka issue atau kirim PR ke `data/opd.json`
- **Peta Proses Bisnis** — Validasi dan tambahkan proses bisnis spesifik per OPD
- **Dokumentasi** — Perbaiki atau tambahkan dokumentasi di `README.md`

### 2. Kode
- **Frontend** — Komponen React di `components/`, halaman di `pages/`
- **API** — Backend di `pages/api/`
- **Styling** — CSS di `styles/globals.css`

### 3. Reporting Issues
Buka issue di GitHub untuk:
- ✅ Koreksi data
- ✅ Validasi konten
- ✅ Saran fitur
- ✅ Bug report

## Sumber Data Resmi
- Diskominfo Kab. Aceh Tengah — Walidata
- Laporan SPBE — Kementerian PANRB
